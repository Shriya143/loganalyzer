# LogLens: Log Analyzer and Error Solver

A full-stack web app built with Java, Spring Boot and an H2 database.

## Features
- Dashboard with charts of 5,000+ real server log lines (Kaggle Apache logs)
- Error Solver: users submit a problem, the app finds a stored solution
- Help Desk form that saves messages to the database
- Admin page to add solutions to unsolved problems

## Tech stack
Java 21, Spring Boot, H2, Chart.js, HTML/CSS/JS

## Run locally
1. Open the project in IntelliJ
2. Run LoganalyzerApplication
3. Open http://localhost:8080/index.html
